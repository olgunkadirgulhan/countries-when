# Countries When... 🌍

Countryball-style animated YouTube Shorts: four countries react to the same situation (snow, breakfast, a football final,
guests coming over...). It closes with "Which one is YOUR country?".

Everything is generated by code: the flag balls, flags, scenes, music and effects. The exclamation voice clips were generated once with Gemini TTS.
Topics are friendly, light stereotypes only, with no politics, war, borders or religion.

- `balls.py`: the engine, built from `src/` by `./build.sh`. `src/bank.py` holds the situations and lines.
- `run.py`: picks a plan (situation plus 4 countries, varied moods, no repeats), renders it and uploads it.
- `.github/workflows/videos.yml`: 3 Shorts a day, but only once the YouTube secrets exist. `comments.yml`: posts first comments and replies.

Preview: `python balls.py --preview 2,6,12 --sit snow --countries CA,BR,TR,JP`
